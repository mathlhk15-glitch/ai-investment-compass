# 뀨의 투자 나침반 v1.2

초보 투자자를 위한 **개인용 투자기록·점검 웹**입니다. 수익 보장, 매매 추천, 자동 주문 기능이 없습니다.

## 첫 실행
1. `index.html`을 열고 기본 안내를 확인합니다. 가능하면 GitHub Pages의 HTTPS 주소에서 실행하세요.
2. 점검 홈에서 **가상 체험 데이터 넣기**를 눌러 보거나, `내 투자 관리`에서 입금 → 매수 순서로 실제 거래를 입력합니다.
3. `관심 종목`에서 종가와 환율을 **직접** 입력합니다. 현재 시세가 자동 반영되지 않습니다.
4. `투자 계획`에서 투자 이유, 반대 근거, 재검토 조건을 씁니다.
5. `설정·백업`에서 JSON 파일을 내려받아 보관합니다. **암호화되지 않은 개인정보 파일**이므로 공개 저장소에 올리지 마세요.

## v1.2 변경사항
- 거래 건수·관심종목 건수의 문자 그대로 표시되는 오류 수정
- 시연용 미국 주식 구입 전 달러 입금 기록 추가
- 존재하지 않는 날짜 입력 거절, 잘못된 종가·환율 기준일 확인
- 음수 잔고를 계산 오류가 아닌 확인 경고로 구분
- 거래 삭제 시 뒤의 거래가 깨지는지 사전 검사
- 계획 링크와 입력된 시세 출처 링크는 HTTP(S)만 허용
- CSV 한국어 인코딩 대응 시도, 선행 0이 있는 6자리 한국 종목코드 보정, CSV 수식 위험문자 내보내기 방어
- 큰 글씨 모드, 고급 비용 입력 접기, 쉬운 안내, 가격 기준일 지연 경고
- 관심종목 삭제, 계획 재검토일 점검, 수동 경제지표임을 명시, 한국·미국 손실 시나리오 구분
- AI 자료 전송 전에 보유 수량·원가·계획이 들어있음을 알리는 확인창

## 계산과 자료에 관한 주의
- 이동평균법을 이용한 **참고용 장부**입니다. 세무 신고용 원가와 실제 증권사 계좌손익은 다를 수 있습니다.
- 주식분할·부분매도·배당·환전 등 기본 사례는 계산 테스트로 확인했습니다. **합병, 권리, 상장폐지, 주식배당, 취득세무 처리, 총수익률(TWR/MWR)은 아직 구현되지 않았습니다.**
- 거래 현금 흐름에 기록하지 않은 과거 입금, 신용거래 등으로 잔액이 음수일 수 있습니다. 이때 실제 증권사 내역과 반드시 대조하세요.
- 미국 주식 주가 효과와 환율 효과 분리는 거래일 환율 기반의 단순 모형이며 실제 환전 손익은 별도로 관리해야 합니다.
- 표시되는 최신 종가·경제지표는 **사용자가 입력한 값**이지 검증된 자동 수집값이 아닙니다. 값의 출처·공개일·기준일을 확인하세요.
- GitHub Pages에 API 키·보유내역·백업 파일을 커밋하지 마세요. 공개 API의 시세 재배포도 별도 이용 약관 검토가 필요합니다.
- 동일 날짜 거래 입력 순서에 따라 당시 보유량 계산이 달라질 수 있습니다. 거래는 증권사 체결 순으로 입력하세요.

## 테스트
`node test_core.js` — 날짜·계산·분할·환율·현금 경고·링크 검사.
브라우저 실사용 시험(화면 배치, 백업 후 복원, 실제 계좌 대조)은 배포 후 별도로 진행해야 합니다.

## GitHub 업로드
압축 파일을 풀어 **index.html, style.css, app.js, core.js** 등을 저장소 루트에 업로드하고, GitHub Settings → Pages에서 배포하세요. 기존 저장소에 올리기 전 개인 거래 JSON/CSV가 섞이지 않았는지 확인하세요.


## v1.2 추가 수정 및 한계
- 중복 CSV 거래를 내용 기준으로 걸러냅니다. 동일 날짜에 같은 수량·가격으로 실제 별도 체결한 거래는 수동 확인이 필요합니다.
- 시장과 통화 불일치, 중복 거래 ID, 배당세 과다 입력을 계산 단계에서 검사합니다.
- 종가가 첫 매입보다 이전이거나 날짜가 올바르지 않으면 평가액 산출을 보류합니다. 오래된 시세는 별도 경고를 보입니다.
- 실존 기업의 실시간 주가·재무제표 자동 수집은 제공하지 않습니다. 공식 API 연계 전에 이용약관/보안 확인이 필요합니다.
- 외부 AI로 개인 데이터를 전송하지 않습니다. AI용 복사 기능 이용 시 내용을 직접 확인하세요.
- CSV 가져오기, IndexedDB 백업/복원, 다양한 모바일 브라우저는 실기기 추가 점검이 필요합니다.
- 숫자 기반 계산 테스트 21개를 통과했습니다. 이는 브라우저 전체 기능과 증권사 회계 일치를 보증하지 않습니다.
- 계산에는 자체 기록된 거래 내역을 사용하며 실제 계좌 전체 자산으로 해석하지 마세요.
